# Product

## Register

product

## Users

Developers who want to run DeepSeek Harness as a local desktop application without installing or managing Node.js and npm separately. Their primary task is to open a workspace and begin a Harness session with minimal setup friction.

## Product Purpose

DSH Desktop provides a secure, reproducible desktop shell around the local DeepSeek Harness Web UI on Linux, macOS, and Windows. Success means the application communicates startup state clearly, opens the local Harness reliably, and stays out of the developer's way.

## Brand Personality

Fast, restrained, trustworthy. Copy should be direct and technical without feeling cold, and progress feedback should reduce uncertainty without adding ceremony.

## Anti-references

Avoid marketing-style splash screens, decorative animation, glassmorphism, oversized cards, fake activity, and long orchestrated loading sequences. Do not make the community wrapper appear to be an official DeepSeek application.

## Design Principles

1. Show real system state instead of generic waiting.
2. Prefer immediate feedback over visual spectacle.
3. Keep familiar desktop conventions and predictable interactions.
4. Preserve user trust through clear errors, local-only behavior, and honest progress.
5. Let the Harness workflow become the focus as soon as it is ready.

## Accessibility & Inclusion

Follow the operating system light or dark preference, maintain WCAG AA text contrast, expose meaningful progress semantics, and provide a reduced-motion alternative for every animation.
